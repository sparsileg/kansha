# Keyboard Shortcuts {.appendix}

## Anywhere

| Key | What it does |
|:---|:---|
| Ctrl+Z | Undo the last register change |
| Ctrl+F | Go to the search box |
| Escape | Close a dialog or menu |
| Arrow keys, in an open menu | Move through the menus |

## In a Register

With a row selected:

| Key | What it does |
|:---|:---|
| ↑ ↓ | Previous or next row |
| Home, End | First or last row |
| Page Up, Page Down | A page up or down |
| Enter | Change the row |
| Space | Mark it cleared, or unmark it |
| Delete | Delete it |
| Insert, Ctrl+N | Go to the entry line |
| Shift+F10, Menu key | The right-click menu |

While entering or changing:

| Key | What it does |
|:---|:---|
| Tab, Shift+Tab | Next or previous field |
| Enter | Save; when changing, move on to the next row |
| Escape | Cancel |

## In a Date Field

| Key | What it does |
|:---|:---|
| `+` or `=` | One day later |
| `-` | One day earlier |
| `t` | Today |

A short date is completed: `3/5` is March 5 of this year.

## In an Amount Field

| Type | Gets |
|:---|:---|
| `12.50+3.25` | A sum, worked out when you move on |
| `3*4.99` | `*` and `/` before `+` and `-` |
| `=` | The sum worked out at once |

## In a Name Field

| Key | What it does |
|:---|:---|
| ↑ ↓ | Move through the matches |
| Enter, Tab | Take the match |
| `:` | Go down a level in a category |
| Escape | Close the list |
