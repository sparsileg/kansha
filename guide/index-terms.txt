# One entry per line:
#   Term                     marks each section's first mention of "term"
#   Term = word; other word  marks the first mention of any of these
#                            (the term itself only if listed)
#   Main, sub = word         a subentry, indented under Main
#   Quicken word => Term     a "see" entry: no pages, points to Term

# starting with # matches only a heading. Lines starting with # are
# comments.

# Very common words (account, category, register, report) match only in
# headings or as longer phrases, or every page would be listed.
